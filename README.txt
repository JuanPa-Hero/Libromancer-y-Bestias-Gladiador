LIBROMANCER & BESTIAS GLADIADOR — Checklist

Contenido del ZIP:
- index.html: app de checklist, funciona en un navegador moderno.
- manifest.json: metadatos básicos para instalación como PWA en hosting compatible.

Cómo usar:
1. Extrae el ZIP.
2. Abre index.html para usar la checklist en el navegador.
3. Marca las cartas que tienes. El progreso se guarda localmente en ese navegador.
4. Puedes exportar/importar el respaldo JSON o descargar CSV desde la app.

Para instalar como aplicación en Android, publica los archivos en un sitio HTTPS (por ejemplo GitHub Pages) y abre la URL en Chrome. El modo sin conexión completo requiere un service worker.

La lista incluye 15 entradas Libromancer y 73 entradas Bestias Gladiador. Se preservan las entradas repetidas de la lista original.
